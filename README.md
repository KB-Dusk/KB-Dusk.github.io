# KB Dusk — Portfolio

My personal developer portfolio built with HTML, CSS and JavaScript. Features a dusk gradient theme with a techy code aesthetic. Hosted live on GitHub Pages.

## Live Site
[KB-Dusk.github.io](https://KB-Dusk.github.io)

## Features
- Dusk gradient colour scheme (purple → pink → orange)
- Responsive navigation with active link highlighting
- Animated code window in hero section
- Typing effect on page load
- Fade in animations on scroll
- Skills grid with hover effects
- Projects showcase with GitHub links
- Contact section

## Sections
- **Hero** — introduction with animated code window
- **About** — brief background and freelance availability
- **Skills** — Python, SQL, Flask, discord.py, Sound Design, JavaScript
- **Projects** — showcase of portfolio projects with GitHub links
- **Contact** — Discord and GitHub contact links

## Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, animations)
- JavaScript (DOM manipulation, IntersectionObserver, event listeners)
- Google Fonts (Fira Code, Inter)
- Hosted on GitHub Pages

## Setup

1. Clone the repository:
   git clone https://github.com/KB-Dusk/KB-Dusk.github.io.git

2. Navigate into the folder:
   cd KB-Dusk.github.io

3. Open in browser:
   open index.html
   
   Or serve locally:
   python3 -m http.server 8000

## Notes
- No frameworks or libraries used — pure HTML, CSS and JavaScript
- Designed with a techy code aesthetic to reflect developer identity
- Update the projects section as new projects are completed
